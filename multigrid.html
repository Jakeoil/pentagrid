Multigrid

De Bruijn's construction for any n — one number, and a reticulum with 2n sides

The method page is the pentagrid. Nothing in it is five-specific except the number: n families of parallel lines, n phases, every crossing a tile, and a dual with ⌊n/2⌋ rhomb shapes. This page is the same view with n chosen here. Odd n spaces the families 2π/n apart round a full turn; even n spaces them π/n apart round a half turn, since a full turn would make family j + n/2 the same lines as family j. The reticulum grows a side for every family.

What does not carry over is worth knowing before you go looking for it. The Penrose dressings — rhomb groups, P1, the matching curves, the deflation, kites and darts, de Bruijn's arrows — are pentagrid facts and are not offered off it. The index still exists at every vertex (it is ∑K), but “four levels at an integer total” leans on ∑vj = 0, which even n loses. The exact regularity criterion is five’s; here the meter can promise regularity for odd n (every offset a non-integer rational, Lutfalla Thm 2.2) and for the uniform grid at any n, and says unproved otherwise. The page opens on the uniform offset — 1/n for odd n, the one setting with global n-fold symmetry; ½ for even, which gives 2n-fold.
